InMemoryCacheSizes ¶

Parameters that control the in-memory cache size of various cached functions.

Parameters:

Name Type Description Default
psf int

The maximum number of PSFs that will be stored in the in-memory cache, which follows the LRU caching strategy. Note, this setting will only take effect by modifying the equivalent environment variable prior to importing microsim.

 64
otf_mb float

The maximum total size (in MB) of Fourier-transformed PSFs that will be kept in memory (LRU) for reuse across simulations with the same optics. Set to 0 to disable. Unaffected by cache.read/cache.write, which control on-disk caching. For GPU backends, this is GPU memory.

 1000

max_psf_radius_aus float | Literal['auto'] | None

Restrict the lateral radius of simulated PSFs to this many Airy radii (1 Airy radius = 0.61 * wavelength / NA, the radius of the Airy disk; half the Airy unit used for Confocal.pinhole_au). 'auto' (default) is our opinionated balance between speed and accuracy, aiming for ~1% RMSE (and <2% max error) relative to an untruncated PSF, which is below shot noise unless pixels collect well over ~10^4 photons. For widefield, the radius grows with the depth of the simulated volume, since out-of-focus light spreads in a cone of half-angle asin(NA/n): it is ~14 Airy radii (for the tails of the in-focus Airy pattern) plus half the radius of that cone at half the volume depth (e.g. ~17 Airy radii for a 1 um deep volume, ~27 for 5 um, at NA 1.4). For confocal, where the pinhole rejects out-of-focus light, it is 8 Airy radii. A number sets the radius directly; a too-small radius loses out-of-focus light (in a 5 um deep widefield volume, 8 Airy radii lose ~20% of it). None uses the full extent of the simulated space (most accurate, but much slower for large volumes: ~2-4x slower per sample than 'auto' at 2048x2048 pixels). The PSF is never larger than the simulated space.

 'auto'
spectral_bins_per_emission_channel int

Number of wavelengths to use (per channel) when simulating the optical image. By default, a single centroid wavelength is used to approximate the emission wavelength. Increasing this will make the simulation more realistic, by superposing multiple different PSFs, but will also increase memory usage and time.

 1
excitation_bin_width_nm float

Maximum width (nm) of the wavelength bins used to represent the excitation light absorbed by each fluorophore, for modalities that focus the excitation (e.g. confocal). Each bin uses a separate excitation spot, so laser lines further apart than this are always simulated separately.

 10
spectral_bin_threshold_percentage float

Percentage of the peak intensity to use as a threshold when binning the emission (and excitation) spectra. This is used to determine the range of wavelengths to consider when simulating the optical image. First, the spectrum is trimmed to include only relevant wavelengths (those with intensity above this threshold). Then, the spectrum is discretized into spectral_bins_per_emission_channel bins (or, for excitation, bins of at most excitation_bin_width_nm).

 1
