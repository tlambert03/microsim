spectral_detector ¶

spectral_detector(
    bins: int,
    min_wave: float,
    max_wave: float,
    lasers: Sequence[int],
    bp_bandwidth: float = 10,
) -> list[OpticalConfig]

Create a spectral detector with a given number of bins and lasers.

Parameters:

Name Type Description Default
bins int

Number of bins to use.

 required
min_wave float

Minimum wavelength to consider.

 required
max_wave float

Maximum wavelength to consider.

 required
lasers Sequence[int]

List of lasers to use.

 required
bp_bandwidth float

Bandwidth of the bandpass filter, by default 10.

 10

Returns:

Type Description
list[OpticalConfig]

List of optical configurations.

Examples:

Create a spectral detector with 8 bins, wavelengths between 480 and 600 nm, and lasers at 488, 515, and 561 nm.

>>> spectral_detector(8, 480, 600, [488, 515, 561])
