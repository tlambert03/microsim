ChannelFluorescence dataclass ¶

ChannelFluorescence()

How bright one fluorophore is in one channel, and at which wavelengths.

This has no spatial information: it describes a single fluorophore at the reference illumination intensity (OpticalConfig.power, summed over the channels of a track that are acquired together), which is the intensity everywhere in a widefield field of view, or at the center of a focused spot. The rates are given with or without saturation at that intensity: modalities that don't illuminate evenly (e.g. confocal) apply saturation locally instead.

Modalities receive one of these for each channel and fluorophore in render().

saturation property ¶

saturation: float

How strongly the fluorophore is saturated at the reference intensity.

This is the (unsaturated) absorption rate times the excited-state lifetime (0 if the lifetime is unknown): I / I_sat for a two-level system. Emission is reduced by a factor of 1 + saturation relative to a linear response: at 1, a fluorophore emits half as much as it would without saturation.

excitation property ¶

excitation: Filter | None

Combine all excitation filters into a single spectrum.

illumination property ¶

illumination: Spectrum | None

Return the combined illumination spectrum.

This represents the spectrum of light source and all of the filters in the excitation path. If there are multiple light sources, they are combined. Different light sources can have different powers. In that case light sources are scaled by the respective light powers.

irradiance property ¶

irradiance: DataArray

Return the illumination irradiance in W/cm^2.

This scales the illumination spectrum to power. It is a measure of the power per unit area of the excitation path of this optical configuration, in W/cm^2, as a function of wavelength.

illumination_flux_density property ¶

illumination_flux_density: DataArray

Return the illumination flux density in photons/cm^2/s.

This is a measure of the number of photons per unit area per second in the excitation path of this optical configuration. It converts irradiance (W/cm^2) to photons/cm^2/s using the energy of a photon.

absorption_rate ¶

absorption_rate(fluorophore: Fluorophore) -> DataArray

Return the absorption rate of a fluorophore with this configuration.

The absorption rate is the number of photons absorbed per second per fluorophore, as a function of wavelength. It's a vector with a single axis W, and singleton dimensions F and C.

saturation_parameter ¶

saturation_parameter(fluorophore: Fluorophore) -> float

Return k * tau: absorption rate relative to the excited-state decay rate.

This is I / I_sat for a two-level system. Returns 0 if the fluorophore lifetime is unknown. See ChannelFluorescence.saturation.

total_emission_rate ¶

total_emission_rate(
    fluorophore: Fluorophore, *, saturate: bool = True
) -> DataArray

Return the emission rate of a fluorophore with this configuration.

The emission rate is the total number of photons emitted per second per fluorophore, as a function of wavelength, prior to any filtering in the emission path. It's a vector with a single axis W, and singleton dimensions F and C. If saturate is True, excitation saturation is applied.

detected_fraction ¶

detected_fraction(
    fluorophore: Fluorophore,
    detector_qe: float | Spectrum | None = None,
) -> DataArray

Return the fraction of absorbed photons that are detected in this channel.

This is the number of photons detected per photon absorbed by fluorophore, as a function of emission wavelength: the quantum yield, times the emission spectrum (normalized to an area of 1), times the transmission of the emission filters and the detector QE. It does not include the fraction of emitted light collected by the objective (see ObjectiveLens.collection_efficiency).

filtered_emission_rate ¶

filtered_emission_rate(
    fluorophore: Fluorophore,
    detector_qe: float | Spectrum | None = None,
    *,
    saturate: bool = True,
) -> DataArray

Return the emission rate of a fluorophore with this config, after filters.

The emission rate is the number of photons emitted per second per fluorophore, as a function of wavelength, after being excited by this optical config, then passing through the emission path of this config. It's a vector with a single axis W, and singleton dimensions F and C.

This is the complete picture of the treatment of a specific fluorophore with this optical configuration. It takes into account:

- the excitation spectrum and extinction coefficient of the fluorophore
- the excitation filter/beamsplitter and light source spectra
- the quantum yield and emission spectrum of the fluorophore
- excitation saturation (unless `saturate` is False)
- the emission filter/beamsplitter spectra
- detector QE: `detector_qe`, or else this config's detector's QE

It does not include the fraction of emitted light collected by the objective (see Simulation.filtered_emission_rates, which does).

emission_band_center ¶

emission_band_center() -> float | None

Center wavelength of the emission filter passband.

This is the midpoint of the band where transmission is above half its peak (as in filter names, e.g. 525/50), combining all filters in the emission path. If they pass several bands, the one transmitting the most light is used, and transmission beyond 900 nm (e.g. near-infrared leaks) is ignored. Returns None if there are no emission filters, or if the band is open-ended: e.g. a longpass filter, still transmitting at the end of its spectrum. (A spectrum that only covers a narrow passband is fine: beyond its data, transmission is 0.)
