cache_path ¶

cache_path() -> tuple[str, ...] | None

Return a tuple of strings that uniquely identify this distribution.

This may be used to determine a cache location for ground truths generated by this distribution. If None is returned, no caching will be performed.

MatsLines ¶

Randomly oriented, one-voxel-wide line segments.

Each voxel on a line holds one fluorophore.

Parameters:

Name Type Description Default
density float

Number of lines, as a fraction of the size of the space along X (in voxels).

 1
length int

Scales the random length of the lines, relative to the field of view.

 10
azimuth int

Limits the tilt of the lines out of the XY plane: larger values give flatter lines.

 10
max_r float

Lines are only drawn within an ellipsoid of this radius, relative to the size of the space (1 touches the edges).

 0.9

Fluorophore ¶

A fluorophore: spectra and photophysical properties.

A string (e.g. "EGFP") may be passed wherever a Fluorophore is expected; its properties are then loaded from FPbase.

Parameters:

Name Type Description Default
name str

Name of the fluorophore.

 required
excitation_spectrum Spectrum

Excitation (absorption) spectrum. Normalized to 1 at its peak when used.

 required
emission_spectrum Spectrum

Emission spectrum. Normalized to unit sum when used.

 required
bleaching_half_life_s float | None

Not used yet.

 None
extinction_coefficient float | None

Molar extinction coefficient at the excitation peak, in M^-1 cm^-1. Required to compute absorption.

 None
quantum_yield float | None

Fraction of absorbed photons that are emitted. Treated as 1 if not set.

 None
lifetime_ns float | None

Fluorescence lifetime in ns, used for excitation saturation. No saturation is applied if not set.

 None

FluorophoreDistribution ¶

A label: a spatial distribution of one fluorophore.

Parameters:

Name Type Description Default
distribution MatsLines | CosemLabel | FixedArrayTruth | Renderable

Generator of fluorophore counts per voxel. Any object with a render(space, xp) method can be used.

 required
fluorophore Fluorophore

The fluorophore. A string is looked up on FPbase. Defaults to a placeholder with flat spectra.

 Fluorophore(name='mockFluorophore', excitation_spectrum=Spectrum(wavelength=ndarray<shape=(500,) dtype=int64>, intensity=ndarray<shape=(500,) dtype=int64>, scalar=1.0), emission_spectrum=Spectrum(wavelength=ndarray<shape=(500,) dtype=int64>, intensity=ndarray<shape=(500,) dtype=int64>, scalar=1.0), bleaching_half_life_s=None, extinction_coefficient=50000.0, quantum_yield=1.0, lifetime_ns=1.0)
concentration float | Callable[list, DataArray] | None

A number to multiply the distribution by, or a function that takes the rendered distribution and returns a modified one.

CosemLabel ¶

Renders ground truth based on a specific layer from a COSEM dataset.

Go to https://openorganelle.janelia.org/datasets/ to find a dataset, and then chose a label from the dataset to render.

Parameters:

Name Type Description Default
dataset str

Dataset ID, e.g. "jrc_hela-3".

 required
label str

Name (or description) of a segmentation or prediction layer in the dataset, e.g. "er-mem_pred".

 required
position tuple[float, float, float] | None

Where the dataset's origin is moved to (in voxels of the resolution level that is read) before the region around 0 is extracted. By default, the region is centered in the dataset.

 None
