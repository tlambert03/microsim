# Tutorials

Longer worked examples. Each one builds a complete simulation and explains the
choices along the way. Each is also a Jupyter notebook: open it in Google
Colab to run it without installing anything, or download it. The figures on
these pages are made by running the code shown.

<div class="grid cards" markdown>

-   :lucide-microscope:{ .lg .middle } **[Two-color imaging of a cell](two-color-cell.md)**

    ---

    Realistic ground truth from OpenOrganelle, fluorophores and filter sets
    from FPbase, and every step of the photon budget plotted. Widefield, then
    confocal.

-   :lucide-shapes:{ .lg .middle } **[Using your own ground truth](your-own-ground-truth.md)**

    ---

    Simulate any 3D array of fluorophore counts, in widefield and confocal.

-   :lucide-scan-line:{ .lg .middle } **[Point-scanning detectors](point-scanning-detectors.md)**

    ---

    PMT high voltage and clipping, photon counting with a HyD, and line
    averaging, on one confocal image.

</div>

More examples are in the
[`examples/`](https://github.com/tlambert03/microsim/tree/main/examples)
folder of the repository.
