# Citing microsim

If you use microsim in published work, please cite the software through its
Zenodo record:

[![DOI](https://zenodo.org/badge/483645397.svg)](https://doi.org/10.5281/zenodo.18942661)

The Zenodo page has citation text in several formats, and a DOI for each
release. Since results can differ between versions, cite the version you used.

The ground truth from OpenOrganelle and the spectra from FPbase come from
other projects; if you use them, please also cite:

- Heinrich, L. et al. "Whole-cell organelle segmentation in volume electron
  microscopy." *Nature* 599, 141–146 (2021).
  [doi:10.1038/s41586-021-03977-3](https://doi.org/10.1038/s41586-021-03977-3)
- Lambert, T. J. "FPbase: a community-editable fluorescent protein database."
  *Nature Methods* 16, 277–278 (2019).
  [doi:10.1038/s41592-019-0352-8](https://doi.org/10.1038/s41592-019-0352-8)
